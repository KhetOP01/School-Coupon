# เครื่องมือ AI ของทีม

| ไฟล์ | อ่านเมื่อ |
|---|---|
| [INSTALL-WINDOWS.md](INSTALL-WINDOWS.md) | ตั้งค่าโปรเจกต์บน Windows และ VS Code |
| [INSTALL.md](INSTALL.md) | ติดตั้งเครื่องใหม่บน Arch Linux |
| [USAGE.md](USAGE.md) | ใช้ workflow ของทีมในแต่ละสถานการณ์ |
| [CONFLICTS.md](CONFLICTS.md) | เครื่องมือทำงานผิดคาดหรือมีเวอร์ชันใหม่ |

กติกาที่ AI ต้องทำตามอยู่ใน `AGENTS.md` ที่ root ของ repo (`CLAUDE.md` import ไฟล์นี้) ส่วน skill ของทีมอยู่ใน `.claude/skills/`

คู่มือ Windows ติดตั้งเฉพาะไฟล์ใน repo และอธิบายส่วนที่ใช้ได้โดยไม่ลงโปรแกรมระดับเครื่อง ส่วน plugin และ hook ที่เหลือให้ติดตั้งแยกตามคู่มือของเครื่องมือเมื่อจำเป็น
