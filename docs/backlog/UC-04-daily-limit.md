# UC-04 ผู้ปกครองตั้งวงเงินใช้จ่ายรายวัน

**Summary:** UC-04 ผู้ปกครองตั้งวงเงินใช้จ่ายรายวัน

**Component:** `student-account`

**Story points:** ?

**Epic:** ยังไม่ระบุ

## User story

ในฐานะผู้ปกครองที่ได้รับอนุญาต

ฉันต้องการตั้งวงเงินใช้จ่ายรายวันของนักเรียน

เพื่อควบคุมการใช้จ่ายโดยไม่เปลี่ยนวงเงินกลางวัน

## กฎทางธุรกิจ

- วงเงินที่ตั้งใหม่มีผลวันถัดไป เวลา 00:00 น. (BR-LIMIT-01)
- วงเงินปัจจุบันมีผลกับรายการ Online และ Offline จนกว่าจะเริ่มใช้วงเงินใหม่

## Acceptance criteria

| รหัส AC | Given | When | Then |
|---|---|---|---|
| **AC4.1** | วงเงินปัจจุบันคือ `100.00` บาท/วัน | Parent ปรับวงเงินเป็น `150.00` บาท/วันระหว่างวัน | สำเร็จ (`200 OK`): บันทึก `next_daily_limit = 150.00`; วงเงินวันนี้คงเป็น `100.00` และวงเงินใหม่มีผลวันถัดไปเวลา 00:00 น. |
| **AC4.2** *(เสนอ)* | คำขอไม่มีวงเงิน หรือส่งวงเงินที่ไม่ใช่จำนวนเงินที่ระบบอ่านได้ | Parent ส่งคำขอตั้งวงเงิน | ปฏิเสธ (`400 INVALID_DAILY_LIMIT`); ไม่เปลี่ยนวงเงินปัจจุบันหรือวงเงินที่รอมีผล |
| **AC4.3** *(เสนอ)* | Student ID ที่ระบุไม่มีในระบบ | Parent ส่งคำขอตั้งวงเงิน | ปฏิเสธ (`404 STUDENT_NOT_FOUND`); ไม่เปลี่ยนข้อมูล |
| **AC4.4** *(เสนอ)* | ผู้เรียกไม่ได้ยืนยันตัวตน หรือไม่มีสิทธิ์ดูแลนักเรียน | ผู้เรียกส่งคำขอตั้งวงเงิน | ปฏิเสธ (`401 AUTHENTICATION_REQUIRED` หรือ `403 PARENT_STUDENT_ACCESS_DENIED`); ไม่เปลี่ยนข้อมูล |
| **AC4.5** *(เสนอ)* | Parent ส่งคำขอตั้งวงเงินค่าเดิมซ้ำในวันเดียวกัน | ระบบรับคำขอซ้ำ | สำเร็จ (`200 OK`) แบบ idempotent; `next_daily_limit` คงค่าเดิมและ `current_daily_limit` ไม่เปลี่ยน |

## นอกขอบเขต

- การบังคับใช้วงเงินขณะซื้อสินค้าอยู่ใน UC-05
- การผูก Parent-Student และการยืนยันตัวตน
- การกำหนดช่วงค่าที่อนุญาตให้ตั้ง ซึ่งยังไม่มีใน PRD

## คำถามที่ต้องตอบ

- วงเงินต่ำสุด/สูงสุดและจำนวนทศนิยมที่อนุญาตคือเท่าใด?
- ถ้าเปลี่ยนวงเงินหลายครั้งในวันเดียว คำขอล่าสุดแทนค่าที่รอมีผลก่อนหน้าหรือไม่?
- เวลา 00:00 น. อ้างอิง timezone ใด?
- เมื่อผู้ปกครองไม่มีสิทธิ์ดูแลนักเรียน ควรตอบ `403` หรือ `404`?

## Sub-tasks (ร่าง)

- `Spec: รีวิว use case และ AC4.1–AC4.5`
- `Spec: ระบุ request/response และ error ของ daily-limit endpoint (AC4.1–AC4.5)`
- `DB: บันทึก current/next daily limit และวันมีผล (AC4.1)`
- `Domain: บังคับการเปลี่ยนวงเงินแบบมีผลวันถัดไป (AC4.1, AC4.5)`
- `App: ตรวจ Student และ Parent access (AC4.3–AC4.4)`
- `HTTP: ตรวจ input และ map error/status ตาม OpenAPI (AC4.2–AC4.4)`
- `E2E: ทดสอบตั้งวงเงินและยืนยันว่าใช้วันถัดไป (AC4.1–AC4.5)`
