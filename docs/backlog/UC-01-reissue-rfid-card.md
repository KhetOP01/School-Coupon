# UC-01 ออกบัตรใหม่และผูกบัตร RFID ทดแทน

**Summary:** UC-01 ออกบัตรใหม่และผูกบัตร RFID ทดแทน
**Component:** `student-account`
**Story points:** ?
**Epic:** ยังไม่ระบุ

## User story

ในฐานะสตาฟโรงเรียนที่ได้รับอนุญาต

ฉันต้องการผูกบัตร RFID ใหม่แทนบัตรเดิมของนักเรียน

เพื่อให้นักเรียนใช้บัตรใหม่ได้โดยยอดเงินใน Wallet ไม่สูญหาย

## กฎทางธุรกิจ

- นักเรียนหนึ่งคนมีบัตร `active` ได้ไม่เกิน 1 ใบ
- เมื่อเปลี่ยนบัตร ยอด Wallet ต้องคงเดิม 100%
- ค่าธรรมเนียมกรณีบัตรหายเก็บแยกเป็นเงินสด ไม่หักจาก Wallet
- บัตรเดิมที่เปลี่ยนได้มีสถานะ `active` หรือ `lost`; UID ที่เคยลงทะเบียนแล้วห้ามใช้ซ้ำ
- คำขอที่ไม่สำเร็จต้องไม่เปลี่ยนสถานะบัตรหรือยอด Wallet

## Acceptance criteria

| รหัส AC | Given | When | Then |
|---|---|---|---|
| **AC1.1** | นักเรียนมีบัญชี, บัตรเดิมเป็น `lost` หรือ `active`, และ UID ใหม่ไม่เคยลงทะเบียน | Staff สแกน UID ใหม่และผูกกับ Student ID | สำเร็จ (`200 OK`): บัตรเดิม `deactivated`, บัตรใหม่ `active`, ยอด Wallet คงเดิม 100% |
| **AC1.2** | UID เคยผูกกับนักเรียนคนอื่น ไม่ว่าสถานะบัตรเดิมเป็นอย่างไร | Staff ส่งคำขอผูก UID นั้น | ปฏิเสธ (`409 CARD_ALREADY_BOUND`); ไม่เปลี่ยนบัตรหรือ Wallet |
| **AC1.3** | Student ID ไม่มีอยู่ในระบบ | Staff ส่งคำขอออกบัตร | ปฏิเสธ (`404 STUDENT_NOT_FOUND`); ไม่สร้างหรือเปลี่ยนบัตร |
| **AC1.4** | คำขอไม่มี Student ID หรือ RFID UID | Staff ส่งคำขอออกบัตร | ปฏิเสธ (`400 INVALID_REQUEST`); ไม่เปลี่ยนข้อมูล |
| **AC1.5** | ผู้เรียกไม่มี Web Admin session ที่ใช้งานได้ หรือไม่มีสิทธิ์ Staff | ผู้เรียกเปิดหน้า Admin หรือส่งคำขอออกบัตร | หน้า Admin พาไปเริ่ม sign-in; API ปฏิเสธ (`401 AUTHENTICATION_REQUIRED` หรือ `403 STAFF_ACCESS_REQUIRED`); ไม่เปลี่ยนข้อมูล |
| **AC1.6** | คำขอพร้อมกันสำหรับนักเรียนคนเดียวกันจะทำให้มีบัตร `active` ซ้ำ | ระบบประมวลผลคำขอพร้อมกัน | ยอมรับไม่เกินหนึ่งคำขอ; คำขอที่ชนกันถูกปฏิเสธ (`409 ACTIVE_CARD_CONFLICT`) และไม่มีข้อมูลเสียหาย |
| **AC1.7** | UID เคยลงทะเบียนกับบัตรของนักเรียนคนเดิมแล้ว รวมถึงบัตร `deactivated` | Staff พยายามใช้ UID เดิมซ้ำ | ปฏิเสธ (`409 CARD_ALREADY_BOUND`) |

## นอกขอบเขต

- การอายัด/ปลดอายัดและการคืนเงินนักเรียนย้ายออก ซึ่งอยู่ใน UC-02
- การรับชำระค่าธรรมเนียมออกบัตรใหม่ด้วยเงินสด
- การออกแบบ Login และการจัดการบัญชีผู้ใช้

## คำถามที่ต้องตอบ

- การเปลี่ยนบัตรจากสถานะ `suspended` หรือ `deactivated` ทำได้หรือไม่?
- รูปแบบ RFID UID ที่ยอมรับคืออะไร?
- ข้อมูล audit สำหรับผู้ดำเนินการ เหตุผล และเวลา ต้องเก็บอย่างไร?
- Staff role ใดบ้างที่ได้รับอนุญาตให้เรียก endpoint นี้?
