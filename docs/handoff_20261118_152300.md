## 2. วิธีการเปิดรันระบบเมื่อกลับมาทำต่อ (How to Resume)

### 🐳 Docker Stack (Backend + Web Admin + Nginx + Postgres)
```powershell
cd D:\School-Coupon
docker compose up -d
```
- **Web Admin (Dev Login):** `http://localhost/dev-login`
- **Web Admin (Login / Dashboard):** `http://localhost/admin/login` หรือ `http://localhost/admin`
- **API Health:** `http://localhost:3000/health`

### 📱 Mobile Apps (Expo Go SDK 58)
*(เนื่องจากเพิ่ง pull โค้ดอัปเกรด SDK 58 เข้ามา ให้รัน `npm install` ก่อนเปิด Expo)*
```powershell
# Merchant POS
cd D:\School-Coupon\apps\merchant-mobile
npm install
npx expo start

# Parent Mobile
cd D:\School-Coupon\apps\parent-mobile
npm install
npx expo start
```
- **เครื่องมือแสดงผลที่มีในเครื่อง:**
  - **มือถือจริง + Expo Go (SDK 58):** ต่อ Wi-Fi วงเดียวกับคอม (`192.168.1.89`) และดู/ควบคุมจอผ่าน `D:\scrcpy-win64-v3.3.3\scrcpy.exe` ได้
  - **Android Studio Emulator:** มี AVD ชื่อ `Medium_Phone_API_36.0` พร้อมใช้งาน (กด `a` ใน Terminal ของ Expo)
