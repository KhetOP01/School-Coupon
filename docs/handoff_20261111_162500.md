## 1. สถานะปัจจุบันของโครงการ (Current Status)

ระบบบริหารจัดการคูปองดิจิทัลโรงเรียน (School Coupon System) ได้พัฒนา ตรวจสอบ และทดสอบผ่านครบ 100%:
- **Backend API (NestJS):** ครบทั้ง 8 Use Cases (UC-01 ถึง UC-08)
- **Web Admin Shell (Next.js):** ออกบัตรใหม่, ระงับ/ปลดระงับบัตร, คืนเงินนักเรียนลาออก, อนุมัติยอดโอน T+1, และระบบ Logout
- **Parent Mobile App:** กระเป๋าเงิน, เติมเงิน PromptPay, ตั้งวงเงินรายวัน, แจ้งอายัดบัตรหาย
- **Merchant Mobile POS:** คิดเงิน Numpad, รองรับเน็ตล่ม (Offline Mode), ซิงก์คิวขึ้นเซิร์ฟเวอร์, ยกเลิกบิลภายในวัน
- **Automated Tests:** **43 Test Suites / 230 Tests ผ่าน 100%** (`npm test`)
- **Full Day Simulation:** สคริปต์จำลองเหตุการณ์จริง 1 วันของโรงเรียนผ่าน 100% (`npm run simulate`)
- **CI/CD Pipeline:** ติดตั้ง GitHub Actions ทำงานอัตโนมัติบน GitHub เรียบร้อย

## 2. วิธีการเปิดรันระบบเมื่อกลับมาทำต่อ (How to Run Later)

### ❓ ทำไมเปิดเบราว์เซอร์แล้วขึ้น "This site can't be reached (ERR_CONNECTION_REFUSED)"?
**สาเหตุ:** เพราะโปรเซสของเซิร์ฟเวอร์หรือ Docker Containers ยังไม่ได้ถูกสั่งสตาร์ท (ใน Docker Desktop จึงขึ้นว่า `No containers are running`)

---

### 🟢 ตัวเลือก A: เปิดรันแบบเร็วที่สุดผ่าน Terminal (แนะนำสำหรับทดสอบหน้าเว็บและ API ทันที)

ไม่ต้องรอบิวด์ Docker ให้เปิด PowerShell หรือ Terminal ในโฟลเดอร์ `D:\School-Coupon` แล้วทำตามนี้:

#### ขั้นที่ 1: เปิด Backend API (เปิดดู Swagger ได้ทันที)
```powershell
npm run start:dev
```
- รอจนขึ้นว่า `Nest application successfully started`
- เปิดเบราว์เซอร์ไปที่:
  - 📖 **Interactive Swagger UI:** [http://localhost:3000/api/docs](http://localhost:3000/api/docs)
  - 📄 **OpenAPI YAML Specification:** [http://localhost:3000/api/openapi.yaml](http://localhost:3000/api/openapi.yaml)
  - 🩺 **Health Check:** [http://localhost:3000/health](http://localhost:3000/health)

#### ขั้นที่ 2: เปิดหน้า Web Admin Dashboard (เปิด Terminal ที่ 2)
```powershell
npm run dev:admin
```
- เปิดเบราว์เซอร์ไปที่:
  - 🖥️ **Web Admin:** [http://localhost:3001/admin](http://localhost:3001/admin)

#### ขั้นที่ 3: ทดสอบรันการจำลอง 1 วันเต็ม (เปิด Terminal ที่ 3)
```powershell
npm run simulate
```
*(คำสั่งนี้จะรันการจำลองตั้งแต่เช้าจรดค่ำ ทดสอบทุก Use Case โดยใช้เวลาเพียงประมาณ 20 วินาที)*

---

### 🐳 ตัวเลือก B: เปิดรันทั้งระบบผ่าน Docker Desktop (Full Production Stack)

หากต้องการรันทุกบริการพร้อมกันและให้ใน **Docker Desktop** ขึ้นคอนเทนเนอร์สีเขียว (Running):

#### ขั้นที่ 1: สั่งเริ่มรัน Docker Compose
เปิด PowerShell ใน `D:\School-Coupon` แล้วพิมพ์:
```powershell
docker compose -f docker-compose.prod.yml up --build -d
```

#### ขั้นที่ 2: ตรวจสอบใน Docker Desktop
ในหน้าโปรแกรม Docker Desktop จะเห็นคอนเทนเนอร์ 4 ตัวทำงานเป็นสีเขียว:
1. `school_coupon_postgres` (ฐานข้อมูล PostgreSQL 16)
2. `school_coupon_api` (NestJS Backend API)
3. `school_coupon_admin` (Next.js Web Admin)
4. `school_coupon_proxy` (Nginx Reverse Proxy ที่พอร์ต 80)

#### ขั้นที่ 3: ลิงก์เข้าใช้งานผ่านพอร์ต 80 (ผ่าน Nginx)
- 🖥️ **Web Admin Dashboard:** [http://localhost/admin](http://localhost/admin)
- 📖 **Swagger API Docs:** [http://localhost/api/docs](http://localhost/api/docs)
- 🩺 **Health Check:** [http://localhost/health](http://localhost/health)

#### ขั้นที่ 4: คำสั่งปิดระบบเมื่อเลิกใช้งาน
```powershell
docker compose -f docker-compose.prod.yml down
```
