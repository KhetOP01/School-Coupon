## 1. สรุปสิ่งที่ทำเสร็จแล้วในรอบนี้ (Session Summary)

### 🗄️ 1. ข้อมูลจริงใน PostgreSQL (5 บัตร RFID จริง + นักเรียนชื่อไทยครบ 35 คน)
- เพิ่มร้านค้า `id = 1` (`M-001`, active) และนักเรียน 5 คน (`id = 1..5`, `STD-1001`–`STD-1005`) ผูกกับบัตร RFID จริง:
  - `1`: `STD-1001` สมชาย ใจดี — `E280F3020000000145A58295`
  - `2`: `STD-1002` สมหญิง รักเรียน — `E280F3020000000145A58285`
  - `3`: `STD-1003` ต้นกล้า มีสุข — `E280F3020000000145A5828D`
  - `4`: `STD-1004` น้ำใส สว่างจิต — `E280F3020000000145A58289`
  - `5`: `STD-1005` ภูผา มั่นคง — `E280F3020000000145A58291`
- อัปเดตชื่อนักเรียนอีก 30 คนใน PostgreSQL เป็นภาษาไทยครบทั้ง 35 คน
- อัปเดต [db/seed.sql](file:///D:/School-Coupon/db/seed.sql) ให้รองรับทั้ง seed 5 คนนี้และคงชื่อ ASCII ในไฟล์ seed เพื่อไม่ให้ติด `WIN1252` encoding ตอนรัน Embedded Postgres บน Windows
